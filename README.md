# 微信小游戏肉鸽 Demo（Cocos 可迁移模块化版本）

本项目已支持：
- 模块化架构（状态/系统/渲染/实体）
- 局外成长（金币 + 永久升级）
- 死亡后激励广告复活（接入点）

## 目录
- `game.js`：微信入口、主循环、场景切换、输入、广告复活
- `src/meta/profile.js`：局外成长（本地存档、结算发币、永久升级）
- `src/services/adService.js`：广告服务封装（激励视频）
- `src/systems/*`：战斗/移动/成长系统
- `src/ui/renderer.js`：菜单、战斗、死亡界面绘制

## 广告建议
- 最优位置：死亡后“看广告复活”
- 次优：局后结算加倍奖励
- 局内：升级界面追加“看广告额外选项”

> 注意：`adunit-demo-rewarded-video` 为占位 ID，上线前替换为你在微信后台申请的真实广告位。

## 美术素材建议（更适配 Cocos）
- 角色、敌人、子弹：透明 PNG，统一锚点中心。
- UI：九宫格按钮 + 位图字体（或动态字体）。
- 图集：TexturePacker / Cocos Auto Atlas，减少 DrawCall。
- 获取渠道建议：
  - 免费：Kenney、OpenGameArt、itch.io 免费包（注意商用协议）
  - 付费高质量：itch.io、Unity Asset Store（2D 包）
  - 国内外包：米画师、猪八戒（可定制风格与版权归属）


## 风险处理（已落地）
- 广告失败提示与降级：广告不可用时给出提示，不再静默失败。
- 广告防连点：复活广告加载期间禁重复触发。
- 局外成长上限与成本曲线：每项最高 20 级，成本按等级增长，避免数值膨胀。
